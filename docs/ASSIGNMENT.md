# 과제 요구사항

## 과제 구성

**아래 순서대로 진행해 주세요.**

| | 내용 | 제출물 | 권장 기간 |
| --- | --- | --- | --- |
| 과제 1 | Flutter 코드로 화면 3개 구현 | GitHub 저장소 링크 | 3일 |
| 과제 2 | `목표가 알림` 화면을 Lucy Studio로 구현 | `cloneProject/assets` 압축 파일 | 1일 |

과제 1을 먼저 마무리한 뒤 과제 2로 넘어가는 것을 권장합니다. 과제 2는 과제 1과 다른 화면이지만, 같은 디자인 토큰을 쓰기 때문에 색상과 서체를 이미 파악한 상태에서 시작하는 편이 빠릅니다.

### 필수와 선택

아래 요구사항은 **필수**와 **선택**으로 나눠 두었습니다.

- **평가는 필수 항목을 기준으로 합니다.** 필수 항목은 모두 구현된 상태로 제출해 주세요.
- **선택 항목은 구현하지 않아도 감점하지 않습니다.** 필수를 먼저 끝내고, 시간이 남을 때 진행해 주세요.
- 필수를 다 못 채운 상태라면 무엇이 남았는지 메모에 적어 주세요.

### 대상 화면

아래는 **과제 1** 의 대상 화면입니다. 안내 메일로 전달드린 Figma 시안의 `Screens` 페이지에 있습니다. 과제 2는 시안이 없는 별도 화면이며 [과제 2](#과제-2-lucy-studio로-목표가-알림-화면-구현)에 설명해 두었습니다.

- `01 · 관심` — 관심종목 목록
- `02 · 검색` — 종목 검색
- `03 · 종목상세` — 종목 상세

나머지 프레임은 별도 화면이 아니라 **위 세 화면의 다른 상태**입니다. 각 화면에 포함해서 구현해 주세요.

| 프레임 | 어떤 상태인지 |
| --- | --- |
| `01 · 관심_empty` | 관심종목이 하나도 없을 때 |
| `01 · 관심_sort` | 정렬 바텀시트가 열려 있을 때 |
| `02 · 검색_empty` | 검색어를 입력하기 전 초기 상태 |
| `02 · 검색결과_empty` | 검색 결과가 없을 때 |
| `04 · 검색 · 관심 등록 토스트` | 검색 화면에서 관심 등록 토스트가 떠 있을 때 |
| `05 · 검색 · 관심 해제 토스트` | 검색 화면에서 관심 해제 토스트가 떠 있을 때 |

### Figma 해석 기준

- **다크 테마 단일 모드**입니다. 라이트 테마는 구현하지 않아도 됩니다.
- 프레임 기준 사이즈는 `393 × 852` 입니다.
- 등락 색상은 국내 시장 관행을 따릅니다. **상승은 빨강(`priceUpText`), 하락은 파랑(`priceDownText`)** 입니다. 반대로 구현하지 않도록 주의해 주세요. 보합(0%)은 `priceFlatText` / `priceFlatBg`를 사용합니다.
- 여백, 폰트 크기, 색상은 Figma 값을 그대로 사용해 주세요.
- `Components` 페이지는 비어 있습니다. 컴포넌트 분리는 직접 판단해서 진행해 주세요.
- 데이터는 실시간으로 바뀌므로 Figma의 숫자와 화면의 숫자가 다른 것은 정상입니다. 숫자 값이 아니라 **표기 형식**을 맞춰 주세요.
- **Figma에 정의되지 않은 상태는 직접 판단해서 처리해 주세요.** 로딩, 네트워크 에러, 긴 종목명의 텍스트 오버플로, 토스트가 사라지는 방식 등이 해당합니다. 어떻게 처리했고 왜 그렇게 했는지 메모에 남겨 주세요. **이 부분을 비중 있게 봅니다.**
  - 빈 상태(관심종목 없음 · 검색 전 · 검색 결과 없음)는 시안이 있으니 시안을 따라 주세요.
- Figma와 다르게 구현한 부분이 있다면 이유를 적어 주세요. 근거가 있으면 문제되지 않습니다.

# 과제 1. Flutter 코드로 구현

상태관리 라이브러리, 폴더 구조, 아키텍처 패턴은 자유입니다. 다만 **왜 그 선택을 했는지 설명할 수 있어야 합니다.** 선택 자체보다 이유를 봅니다.

캔들 차트는 패키지를 사용해도 되고 직접 `CustomPainter`로 그려도 됩니다.

**차트 안쪽의 그림은 시안과 달라도 감점하지 않습니다.** 캔들 두께와 간격, 여백, 축 눈금, Y축 범위를 잡는 방식 같은 렌더링 디테일은 도구에 따라 달라질 수밖에 없습니다. 다만 아래는 지켜 주세요.

- 차트 높이가 시안과 조금 달라지는 것은 괜찮습니다. **차트 위아래 요소들의 배치가 시안과 어긋나지 않을 정도면 됩니다.**
- 상승 / 하락 캔들 색상(`chartLineUp` / `chartLineDown`)은 맞춰 주세요.
- 캔들 차트를 지원하면서 토큰 색과 시안의 여백까지 맞추기 쉬운 패키지는 많지 않습니다. 패키지를 쓰신다면 시안과 달라진 부분과 그 이유를 메모에 적어 주세요.

이 예외는 **차트에만 해당합니다.** 나머지 화면 요소는 시안 값을 그대로 사용해 주세요.

데이터 연동은 [`NAVER_API.md`](NAVER_API.md)를 참고하세요.

## 1. 관심 화면 (`01 · 관심`)

**필수**

- 관심종목 각 행에 아래 정보를 표시합니다.
  - 종목명
  - `종목코드 · 시장` (예: `005930 · 코스피`)
  - 현재가
  - 전일 대비 등락액과 등락률 (예: `-400 (-0.22%)`)
- 등락에 따라 색상이 바뀝니다. **상승 / 하락 / 보합 세 가지 상태를 모두 처리해 주세요.**
- 상단 새로고침 버튼을 누르면 시세를 다시 조회합니다.
- 하단 탭 바로 관심 / 검색 화면을 전환합니다. `navActive` / `navInactive` 상태 스타일이 다릅니다.
- 아직 시세를 받지 못한 행은 스켈레톤 상태로 표시합니다. (`feedbackSkeleton`)
- 관심종목이 하나도 없을 때 빈 상태를 표시합니다. (`01 · 관심_empty`)
  - 별 아이콘, `관심 종목이 없습니다`, 안내 문구까지 시안대로 맞춰 주세요.
  - 이때도 헤더와 하단 탭 바는 그대로 유지됩니다.
- 정렬 기능이 동작합니다. (`01 · 관심_sort`)
  - 헤더 우측에 현재 정렬 기준을 보여주는 칩이 있고, 누르면 정렬 바텀시트가 열립니다.
  - 정렬 기준은 `현재가순`, `등락률순`, `가나다순` 세 가지이며 선택된 항목에 체크 표시가 붙습니다.
  - 선택하면 목록 순서가 바로 바뀌고 헤더 칩의 문구도 함께 바뀝니다.

**선택**

- Pull to refresh
- 관심종목 삭제 (스와이프 등)
- 정렬 기준을 앱 재실행 후에도 유지

> 시세를 아직 받지 못한 행이 섞여 있을 때 `현재가순` / `등락률순`에서 그 행을 어디에 둘지는 시안에 없습니다. 직접 판단하고 메모에 적어 주세요.

## 2. 검색 화면 (`02 · 검색`)

**필수**

- 검색 입력창과 입력 내용을 지우는 버튼이 있습니다.
- 검색 결과 각 행에 아래 정보를 표시합니다.
  - 종목명 — **검색어와 일치하는 부분을 하이라이트** 처리합니다. (`searchHighlight`)
  - `종목코드 · 시장`
  - 관심 등록 버튼 (별 아이콘). `favoriteActive` / `favoriteInactive`로 상태가 달라집니다.
- 별 아이콘을 누르면 관심 등록 / 해제가 즉시 반영됩니다.
- 등록 / 해제 시 화면 하단에 토스트를 띄웁니다.
  - 등록: 채워진 별 아이콘 + `관심이 등록되었습니다`
  - 해제: 비어있는 별 아이콘 + `관심이 해제되었습니다`
  - 배경, 라운드, 아이콘과 문구의 간격을 Figma 기준으로 맞춰 주세요.
- 검색 결과 행을 누르면 종목 상세 화면으로 이동합니다.
- 검색어를 입력하기 전 초기 상태를 표시합니다. (`02 · 검색_empty`)
  - 돋보기 아이콘, `종목을 검색해 보세요`, 안내 문구까지 시안대로 맞춰 주세요.
- 검색 결과가 없을 때 빈 상태를 표시합니다. (`02 · 검색결과_empty`)
  - 안내 문구에 **사용자가 입력한 검색어가 그대로 들어갑니다.** (`'{검색어}'와 일치하는 검색 결과를 찾지 못했습니다.`)
  - 입력을 지우면 다시 초기 상태로 돌아갑니다.

**선택**

- 입력 디바운스 처리
- 검색어 입력 중 로딩 표시
- 최근 검색어
- 토스트 등장 / 퇴장 애니메이션

> 토스트 노출 시간과 사라지는 방식, 검색어가 매우 길 때 빈 상태 문구를 어떻게 다룰지는 Figma에 정의되어 있지 않습니다. 직접 판단하고 메모에 적어 주세요.

## 3. 종목상세 화면 (`03 · 종목상세`)

**필수**

- 상단에 뒤로 가기, 종목명, `종목코드 · 시장`, 관심 등록 버튼이 있습니다.
- 현재가와 전일 대비 등락을 크게 표시합니다. 등락 방향 아이콘(▲ / ▼)이 함께 붙습니다.
- 기간 탭 `1개월` / `3개월` / `6개월` / `1년` 이 **모두 동작해야 합니다.**
  - 선택된 탭은 `accentDefault` / `accentBg` 스타일이 적용됩니다.
  - 탭을 바꾸면 차트와 일별 시세 표에 표시되는 기간이 바뀝니다.
- 캔들 차트를 표시합니다. 상승 / 하락 캔들은 `chartLineUp` / `chartLineDown`을 사용합니다. 기간에 맞는 캔들이 그려지면 필수 요건은 충족입니다.
- 요약 카드로 `시가`, `고가`, `저가`, `거래량`, `시가총액`을 표시합니다. 거래량과 시가총액은 축약해서 표기합니다. (예: `29,113천`, `1,063조`)
- `일별 시세` 표를 표시합니다.
  - 컬럼: `날짜`, `종가`, `등락`, `거래량`
  - 날짜는 `MM.DD` 형태, 등락은 부호와 색상을 함께 표시합니다.

**선택**

- 차트 축 라벨, 거래량 바 (`chartAxisLabel`, `chartVolumeBar` 토큰이 준비되어 있습니다)
- 차트 영역 채우기 (`chartAreaUp`, `chartAreaDown`)
- 차트 터치 시 크로스헤어 / 툴팁
- 일별 시세 표의 무한 스크롤
- 차트 전환 애니메이션

## 4. 상태 동기화 (전체 필수)

- 관심 상태가 바뀌면 관심 화면, 검색 화면, 상세 화면의 별 아이콘이 모두 함께 바뀝니다.
- 검색 직후에도 현재 관심 상태가 결과에 반영됩니다.
- 검색 화면에서 관심 등록한 종목이 관심 화면 목록에 반영됩니다.
- 상세 화면에서 관심을 해제하고 돌아오면 목록에도 반영됩니다.

> 관심 목록을 앱 재실행 후에도 유지하는 것(로컬 저장)은 **선택**입니다.

정적 분석은 필수입니다.



# 과제 2. Lucy Studio로 `목표가 알림` 화면 구현

저희 플랫폼 **Lucy Studio**로 `목표가 알림` 화면 하나를 만듭니다. **과제 1의 세 화면과는 무관한 새 화면입니다.** 안내 메일로 전달드린 시안과 아래 설명을 보고 구성해 주세요.

관심종목의 목표가를 등록해 두는 화면입니다. 목록에 등록된 목표가가 쌓이고, `+` 버튼으로 새 항목을 추가합니다. 시안에 `빈 상태` · `등록 다이얼로그` · `등록된 목록` 세 가지 상태가 있습니다.

**데이터 연동은 필요 없습니다.** 실제 시세를 불러오거나 알림을 보내지 않아도 됩니다. 종목명과 목표가는 사용자가 입력한 값을 그대로 쓰면 됩니다.

## 시작하기

공식 문서에 필요한 내용이 모두 있습니다. → https://docs.edencrew.com/

먼저 볼 섹션은 아래와 같습니다.

- `시작하기` — 다운로드, 설치, 초기 설정
- `Lucy Team Cloud에서 프로젝트 관리하기` — 계정과 워크스페이스
- `튜토리얼 & 실습` — 처음이라면 여기를 한 번 따라 해보시는 걸 권합니다
- `레이아웃 & 화면 설계` — 화면 구성과 반응형
- `스타일 & 디자인 시스템` — 색상과 타이포그래피 정리
- `위젯 사용` — 개별 UI 요소

버튼을 눌렀을 때 다이얼로그를 열고 리스트에 항목을 더하는 부분은 이벤트와 데이터를 다루는 섹션에 나옵니다. 문서에서 해당 부분을 찾아 보시면 됩니다.

### 스크립트 작성 시 참고

- dialog를 열고 닫는 동작은 주로 `$form`에서 제공하는 함수를 사용합니다.
- 위젯의 property를 스크립트로 수정할 때는 `setProperty`를 사용합니다.
- 위젯의 property 값을 읽을 때는 `getProperty`를 사용합니다.
- 그 외에 필요한 함수는 docs를 참조해 작업해 주세요.
- 원하는 아이콘이 없는 경우에는 SVG 이미지를 사용하시는 것을 권장합니다. SVG에 `onTap` 이벤트를 붙이면 스크립트로 클릭 동작을 처리할 수 있습니다.

처음 쓰는 도구이므로 익숙하지 않은 것은 문제되지 않습니다. 문서를 보고 얼마나 빠르게 파악해서 결과물을 만들어내는지를 봅니다. 

## 구현해야 할 내용

하나의 페이지로 만들면 됩니다.

**필수**

- 헤더에 `목표가 알림` 제목과 우측 `+` 버튼이 있습니다. `+` 는 accent 색을 씁니다.
- **등록된 목록** — 각 행에 좌측 **종목명**, 우측 **목표가**가 놓이고 행 사이에 구분선이 있습니다.
  - 목표가는 천 단위 구분 쉼표를 넣습니다. (예: `200,000`)
  - 행은 컴포넌트로 분리해 재사용합니다.
- **빈 상태** — 항목이 하나도 없을 때 아이콘, `등록된 알림이 없습니다`, 그리고 `우측 상단 + 버튼을 눌러 목표가를 추가해보세요` 안내 문구를 표시합니다. 이때도 헤더는 그대로 유지됩니다.
- **등록 다이얼로그** — `+` 버튼을 누르면 열립니다.
  - 제목은 `목표가 알림 추가` 입니다.
  - 입력 항목은 `종목명` 과 `목표가` 두 개이며, 각각 위에 라벨이 붙습니다.
  - `목표가` 입력칸의 placeholder 는 `숫자만 입력` 입니다.
  - 우측 하단에 `매도` 와 `매수` 버튼이 있습니다. 두 버튼 모두 입력한 항목을 등록하며, 어느 쪽을 눌렀는지가 항목의 구분이 됩니다.
  - 닫기는 다이얼로그 우측 상단의 `x` 아이콘입니다.
  - 다이얼로그가 열려 있을 때 뒤 화면은 어둡게 가려집니다.
- **등록하면 입력한 항목이 리스트에 실제로 추가됩니다.** 화면을 그려두는 것만으로는 부족하고, 눌러서 동작하는 상태여야 합니다.
- `x` 아이콘을 누르면 아무것도 추가되지 않고 닫힙니다.
- 색상 · 서체 · 간격은 과제 1과 같은 디자인 토큰을 사용합니다. (`lib/theme/README.md` 의 대응표 참고)

**선택**

- 디자인 토큰을 Lucy Studio에서 지원하는 방식으로 정의해 두고 참조하기
- 종목명, 목표가 텍스트 필드 입력값 검증
- 항목 삭제

**직접 판단할 부분**

- 시안에 여백과 폰트 크기가 수치로 지정되어 있지 않은 부분은, 과제 1의 간격 · 서체 토큰을 참고해 화면에 어울리게 잡아 주세요.
- 목표가에 `원` 같은 단위를 붙일지 여부
- `목표가` 입력칸에서 숫자만 입력되도록 제한할지, 아니면 입력은 열어두고 등록 시점에 걸러낼지도 직접 판단하시면 됩니다. 필수는 빈 값에 대한 검증까지입니다.

사용할 위젯이나 기능에 제약은 없습니다.
